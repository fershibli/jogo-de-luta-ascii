Absurdo

Jogo de luta em ASCII feito no 1º semestre de Jogos Digitais (2013), com uma thread para cada coisa: teclado, golpes, animação, inimigo e tela. O código original roda aqui em Python via Pyodide; as threads viram tarefas cooperativas no mesmo ritmo dos time.sleep originais.

Escolha quanto quer de ataque (0 a 10), mova com W A S D e alterne H J K L para atacar. Quer jogar contra um amigo? Versão em rede.
